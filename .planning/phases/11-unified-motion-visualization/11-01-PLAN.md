# Plan 11-01: Unified Motion visual quality

## Goal

Make the one visible Motion canvas a readable, behaviour-driven visualization of
ordinary Python execution, with a real call stack, collection primitives and
recorded node-link shapes, without changing the tracer, the trace format, the
deterministic planner, the renderer registry or the shared cursor.

## Scope

1. **Call stack.** Vertical frames, newest first. Show function, recorded depth,
   running/calling line, locals, and active/waiting/returning state. A returning
   frame carries the recorded value. Keep the most recent calls and state the
   count of earlier calls that remain in the Inspector.
2. **Generic primitives.** Scalar transitions show the previous snapshot as
   `old -> new`. The first cursor position introduces the run; a step with no
   drawable change shows its line and an honest short note.
3. **Recorded shapes.** Class instances that reference one another compose into
   a linked list, tree or graph. Adjacency lists are followed one hop. Objects
   with no recorded references keep their generic cards.
4. **Sorting and collections.** Keep the existing cell composition, comparison
   ring, swap/shift animation, settled green and per-cell indices; widen the
   phone breakpoint so values stay readable.
5. **Verification.** Unit tests for frame states, scalar transitions and shape
   classification; browser checks and screenshots for linked list, tree, graph
   and a deep recursion stack.
6. **Bookkeeping.** Update progress docs and this phase summary.

## Out of scope

- Any tracer, trace-format or planner change.
- A second renderer, a third panel, or an external AI dependency.
- Changing the 122-case planner baseline or removing internal renderer ids.
